# Anemoia

**EN**

1. Click **Code → Download ZIP** and unzip it.
2. Open `vivaldi://extensions` (or `chrome://extensions`) and turn on **Developer mode**.
3. Click **Load unpacked** and select the `extension` folder.
4. Vivaldi: **Settings → Tabs → New Tab Page → Controlled by Extension**.
5. Open a new tab.

**RU**

1. Нажмите **Code → Download ZIP** и распакуйте архив.
2. Откройте `vivaldi://extensions` (или `chrome://extensions`) и включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное** и выберите папку `extension`.
4. Vivaldi: **Настройки → Вкладки → Новая вкладка → Управляется расширением**.
5. Откройте новую вкладку.
